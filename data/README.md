# App directory data

`bengaluru-community-options.json` is the source-linked directory used by Common Ground. It currently contains 31 public event calendars and organiser-led opportunities across books, creative activities, music, nature, volunteering, and learning. Entries include organiser source links and a `checkedOn` date. Time-limited activities use `activeUntil` so the app stops showing them after the listed date. Keep costs, requirements, and event details faithful to the linked source; use `null` or a clear "ask organiser" label when the source does not publish them.

`bengaluru-places.csv` and `Bengaluru_Places_Catalog.xlsx` are retained from the previous Bengaluru place-discovery prototype. The current app does not read or deploy those files.
